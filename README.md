## ✨ المميزات
- 4 أنواع مشاريع: موقع ويب • بوت تيليجرام • بوت ديسكورد • أداة Python
- المواقع والبوتات تصلك **ملف ZIP** جاهز + `HOSTING_GUIDE.md` — وأدوات Python تصلك **ملف `.py` واحد** مباشرة
- قوالب جاهزة لكل نوع + إمكانية كتابة فكرة حرة
- رفع لوجو/صور (مع وصف في التعليق) وإدراجها داخل المشروع
- **تعديل أي مشروع سابق** بطلب نصي، وأرشيف «مشاريعي» لإعادة التحميل والحذف
- إعدادات: ستايل المواقع (داكن / فاتح / زجاجي) ولغة المشروع (عربي / English)
- شريط تقدم متحرك أثناء التوليد + طابور عادل
- حد يومي (5 مشاريع) وفترة انتظار (60 ثانية) — الأدمن بلا حدود
- أقسام: الاستضافة • المميزات • المطور • المساعدة

## 🛠 حل المشاكل
افتح ملف **`bot.log`** (أو سجل الاستضافة). البوت يفحص نفسه عند التشغيل ويرسل للأدمن رسالة بالنتيجة.

| الرسالة في السجل | المعنى والحل |
|---|---|
| `BOT_TOKEN ... malformed` | التوكن في `config.py` ناقص أو فيه مسافة زائدة |
| `401 Unauthorized` | التوكن غير صحيح أو تم إلغاؤه من BotFather |
| `409 Conflict` | نفس التوكن يعمل في مكان آخر — أوقف النسخة الأخرى |
| `Could not connect to Telegram` | الاستضافة تحجب الاتصال بتيليجرام |
| `Gemini check failed` | مفتاح Gemini أو اسم الموديل غير صحيح |
| `ModuleNotFoundError` | لم يتم تثبيت `requirements.txt` على الاستضافة |

المسارات تُحسب دائمًا بالنسبة لمكان `main.py`، وإن كان المجلد للقراءة فقط يستخدم البوت مجلد temp تلقائيًا.

## 🐙 الرفع على GitHub
- ملف `.gitignore` يمنع رفع `config.py` (فيه التوكن والمفتاح) — الذي يُرفع هو `config.example.py`.
- على أي جهاز جديد: انسخ `config.example.py` إلى `config.py` واملأ القيم.
- إن رفعت التوكن بالخطأ، غيّره من BotFather وأنشئ مفتاح Gemini جديد.
